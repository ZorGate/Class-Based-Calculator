# Class-Based-Calculator
A 4-function Calculator, now with scientific notation!! This project mainly served as something of a HelloWorld-esque project for me, as, prior to building it, I knew pretty much no Java whatsoever. Fortunately, as a result of the work I've done on this project, that has changed (I know the basics now at least!) Anyway, enough from me- time for you to try it out for yourself!

## How do I run this thing???
1: Download the .zip from releases
2: Extract the .zip
3: Open the Class-Based-Calculator folder
4: Click on Class-Based-Calculator.exe
Enjoy!!
