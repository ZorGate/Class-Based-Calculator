# Class-Based-Calculator
A terminal-based 4-function Calculator, now  with scientific notation!! This project mainly served as something of a HelloWorld-esque project for me, as, prior to building it, I knew pretty much no Java whatsoever. Fortunately, as a result of the work I've done on this project, that has changed (I know the basics now at least!) Anyway, enough from me- time for you to try it out for yourself!

## How do I run this thing???
The first step, like always, is to clone the repo to your computer:
```sh
git clone https://github.com/ZorGate/Class-Based-Calculator.git
```

Next, if you haven't already done so, install the latest version of Java:
[download java](https://www.java.com/en/download/)
To check if yor download was successful, run
```sh
java --version
```

Lastly, to run the program, navigate to the folder that you cloned the repo to, and enter in the terminal:
```sh
java Calculator
```

Enjoy!!
